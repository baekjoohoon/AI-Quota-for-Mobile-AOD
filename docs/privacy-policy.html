개인정보 처리방침

최종 업데이트: 2026년 5월 26일

AI Quota는 Android 기기에서 AI provider의 남은 사용량과 reset 시간을 확인하기 위한 앱입니다.

앱이 처리하는 정보

AI Quota는 사용자가 직접 연결한 provider 세션 또는 OAuth 연결을 사용해 quota snapshot을 확인합니다. 앱은 표시를 위해 다음 정보를 기기 안에 저장할 수 있습니다.

  • provider ID와 provider 이름
  • plan label
  • 사용량 항목 이름
  • 남은 사용량 비율
  • reset time
  • 마지막 수집 시각
  • stale, auth-required 같은 표시 상태
  • provider별 WebView 세션 데이터 또는 OAuth 기반 로컬 세션 상태

Gemini 또는 Antigravity 연결에 Google OAuth가 사용되는 경우, AI Quota는 사용자가 승인한 범위 안에서 Google 계정의 기본 프로필, 이메일 주소, Google Cloud 또는 Code Assist 관련 사용량 확인에 필요한 응답을 처리할 수 있습니다. 이 정보는 provider 연결 상태 표시와 사용량 snapshot 생성을 위해 사용됩니다.

개발자 서버로 전송하지 않는 정보

AI Quota는 다음 정보를 개발자 서버로 전송하지 않습니다.

  • raw token
  • raw cookie
  • OAuth secret
  • OAuth callback code
  • auth header value
  • provider API key
  • provider credential file
  • full provider HTML
  • raw provider response log

provider 및 제3자 서비스

AI Quota는 사용자가 선택한 provider의 웹사이트 또는 API에 연결될 수 있습니다. 이 과정에서 provider는 자체 개인정보 처리방침에 따라 계정 식별 정보, 세션 쿠키, OAuth 토큰 등을 처리할 수 있습니다.

AI Quota는 각 provider의 공식 앱이 아니며, 각 provider와 제휴되어 있지 않습니다.

알림과 위젯

AI Quota는 사용자가 활성화한 경우 홈 화면 위젯과 상태 표시줄 알림에 quota snapshot을 표시합니다. 이 정보는 기기에 저장된 표시용 cache를 기반으로 합니다.

데이터 보안

provider 및 OAuth 통신은 HTTPS 기반 연결을 사용합니다. 로컬 cache, WebView 세션 데이터, OAuth 기반 로컬 세션 상태는 Android 앱 저장소에 보관됩니다. AI Quota는 Google 사용자 데이터를 판매하지 않으며, 앱 기능 제공 목적 외로 공유하지 않습니다.

데이터 보관 및 삭제

로컬 snapshot과 세션 데이터는 앱의 연결 해제, 앱 데이터 삭제, provider 연결 해제, 또는 앱 제거를 통해 삭제할 수 있습니다.

데이터 삭제 요청은 Google Play에 표시된 개발자 연락처를 통해 요청할 수 있습니다. 요청 시 계정 확인에 필요한 정보를 제공해야 할 수 있습니다.

아동

AI Quota는 아동을 대상으로 하지 않습니다.

문의

개인정보 관련 문의는 Google Play에 표시된 개발자 연락처를 통해 요청할 수 있습니다.
